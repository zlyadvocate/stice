# stice
**C++17 ICE + TURN client library, ported from [pion/webrtc](https://github.com/pion/webrtc) (Go), designed as a drop-in replacement for [libjuice](https://github.com/paullouisageneau/libjuice).**  stice implements the ICE (Interactive Connectivity Establishment, RFC 8445) agent and TURN (Traversal Using Relays around NAT, RFC 8656，RFC 6062) client in modern C++17, with a stable C ABI. It provides both a native `stice_*` API and a full `juice_*` compatibility layer, allowing existing libjuice consumers (such as [libdatachannel](https://github.com/paullouisageneau/libdatachannel)) to switch with a mechanical rename.
